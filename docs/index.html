Model Context Protocol + QA Automation

From a prompt to real test automation

This demo shows how an MCP-enabled assistant can understand a natural-language request, observe a browser flow, and generate automation artifacts like feature files, step definitions, and page objects in a few simple steps.

What this MCP workflow does

  • Receives a prompt such as “Open Google and search for automation demo”.
  • Launches a real browser and performs the interaction.
  • Generates reusable test assets for Cucumber and Playwright.
  • Connects chat-style instructions with actual automation execution.

Why it is useful

  • Reduces manual setup when creating new test flows.
  • Makes automation easier for non-developers to describe.
  • Shows a modern agent-style workflow for QA teams.
  • Bridges natural language with real browser automation.

Traditional automation

  • Hard-coded scripts written manually.
  • Requires explicit selectors and test steps.
  • Needs more maintenance as flows change.

MCP-assisted automation

  • Starts from a simple prompt.
  • Uses a tool/agent to observe the browser.
  • Generates structured test assets automatically.
